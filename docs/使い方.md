# みんなで管理の見方と使い方

ゴミ出し、清掃、業者の立ち会いを、住人で交代する試作品です。スマホの縦画面で見る想定です。パソコンでも、中央の細い画面で同じように操作できます。

まだ試作品です。入力した担当やメモは、そのスマホの中だけに残ります。ほかの人の画面とは共有されません。

## 開く

https://minnade-kanri.vercel.app

ホーム画面に追加すると、アプリのように開けます。

## 入る

1. 合言葉に `1234` と入れて、「合言葉を確認する」を押す。
2. 「あなたはどの部屋ですか？」から、自分の部屋を選ぶ。

最初は4人から部屋を選びます。306岩崎はシステム管理者です。最初の管理者は505松浦です。住人の追加や、誰を管理者にするかは、あとから管理画面で変えられます。

画面上部の「今のユーザー（デモ用）」で、見ている人を切り替えられます。説明のときは、住人の画面と管理者の画面をここで見せ分けます。

最初から入っている担当は見本です。変えすぎたあとに戻すときは、「サンプルのシフトに戻す」を押します。それまでの担当とメモは消えます。

## カレンダーの見方

下の「カレンダー」が、いつ誰が担当かの画面です。

- 「前月」「今月」「翌月」で月を変える。日曜と月曜はお休みで、担当はありません。
- 通常は「1週目」「2週目」のタブです。今日を含む週が最初に開きます。
- 日付のカードには、ゴミの種類、担当者、報酬が出ます。空きは「空き枠（募集中）」です。
- 緑のふちは、空きがある日です。「今日」は緑の枠で囲みます。
- 交代を頼んでいる日には「交代してください🙏」と出ます。決まるまで、もとの担当者のままです。
- 「+1,000円」は特別手当です。その日の報酬は6,000円です。ふだんは5,000円です。
- 「備考あり」は、立ち会いの時間など、管理者からのメモがある日です。

ゴミの色は、画面上部の丸い印と同じです。

| 曜日 | ゴミ |
| --- | --- |
| 日曜・月曜 | お休み |
| 火曜 | リサイクル。第4火曜だけ不燃 |
| 水曜・土曜 | 燃える |
| 木曜 | プラ |
| 金曜 | ペット |

## 日付を押したとき

その日の詳細が開きます。報酬、備考、前日の申し送り、担当者が見えます。申し送りは、直前に仕事があった日のメモです。日曜・月曜をはさむときも、その前の稼働日のメモを見ます。

空き枠がある人は「この日を担当する」を押せます。同じ日に、同じ人が2枠入ることはできません。

自分が担当の日は、次ができます。

- 「申し送りメモを書く」で、次の人へ伝える。例は「雨のため外掃除スキップしました」。書き終わったら「申し送りを保存」。
- 「交代を募集する（キャンセル）」で、代わりの人を募る。やめるときは「交代の募集を取り消す」。

交代を引き受ける人には「交代で担当する」が出ます。

## 自分の日と空き枠だけ見る

カレンダーのボタンは、押すとひと月分の小さなカレンダーに変わります。金額は出ません。緑の日だけが、探している日です。もう一度押すと、週ごとの一覧に戻ります。

- 「自分の担当日のみ表示」: 緑の日に「担当」と出ます。
- 「空き枠のみ表示」: 空きと、交代募集中の日に「空き」と出ます。
- 両方押すと、自分の担当で、かつ空き枠もある日だけが緑になります。

日付を押すと、いつもと同じ詳細が開きます。

## 報酬集計

下の「報酬集計」を押します。見ている月の数字です。月はカレンダーと同じ「前月」「今月」「翌月」で変えます。

- 稼働枠、確定、空き枠、交代募集の数
- 確定した報酬の合計。空きがすべて埋まったときの見込みも出ます
- 「もし、空いている枠をあなたが担当すると」は、いまの自分があと何回入れそうかの試算です。すでに入っている日は数えません
- 「部屋ごとの報酬」は、登録されている住人それぞれの回数と金額です。見ている人の行が緑になります。振込先が登録されている人は、名前の右に銀行名と口座番号の下4桁が薄いグレーで出ます

「この月の報酬をCSVでダウンロード」で、その月の表を保存できます。ファイル名は `報酬集計-2026-11.csv` のように月が入ります。中身は部屋、名前、担当回数、特別手当回数、報酬、銀行名、支店名、口座種別、口座番号、口座名義と、最後の合計です。Excelで開ける形式です。試算の「もし担当すると」は入りません。

## 住人と管理者

306岩崎で入ると、下に「管理」が出ます。

- 「住人を追加」で、部屋と名前を登録する。追加した人は住人から始まり、ログインの部屋一覧にも出ます。
- 各住人の「編集」で、部屋、名前、振込先の口座を直す。すでに入っている担当は、同じ人のまま名前だけ変わります。
- 右端の「管理者にする」「住人に戻す」で、役割を変える。

追加した住人も、役割も、振込先も、そのブラウザに保存されます。「サンプルのシフトに戻す」を押しても、住人、役割、振込先は戻りません。同じ部屋番号は登録できません。

システム管理者は、この画面を使う人です。管理者は、次の操作ができる人です。両方を同じ人にすることもできます。

## 管理者だけできること

管理者で見ているとき、日付の詳細の下に「管理者の操作」が出ます。

- 備考を書く。例は「10:00〜 消火栓点検の立ち会いあり」
- 「特別手当（+1,000円）を付与」で、その日を6,000円にする
- 「募集人数を2名にする」で、台風の翌日や大掃除の日を2人にする。2枠目に人が入っているときは、先に空きへ戻さないと1人には戻せません
- 「代わりに担当者を決める」で、スマホが苦手な人の代わりに担当を入れる。空欄にすると空き枠に戻ります

2人の日は、担当した人それぞれに同じ報酬が付きます。

## データについて

担当、メモ、見ている人、住人の部屋と名前、振込先、誰が管理者かは、そのブラウザに保存されます。別のスマホで開くと、最初の見本から始まります。サーバーにはまだ送っていません。
