# みんなできれいの見方と使い方

ゴミ出し、清掃、業者の立ち会いを、住人で交代する試作品です。スマホの縦画面で見る想定です。パソコンでも、中央の細い画面で同じように操作できます。

まだ試作品です。担当、メモ、住人、振込先は、そのスマホの中だけに残ります。ほかの人の画面とは共有されません。

## 開く

https://minnade-kirei.vercel.app

ホーム画面に追加すると、アプリのように開けます。

## 入る

1. 合言葉に `1234` と入れて、「合言葉を確認する」を押す。
2. 「あなたはどの部屋ですか？」から、自分の部屋を選ぶ。

最初の部屋は次の4つです。

| 部屋 | 名前 | 最初の役割 |
| --- | --- | --- |
| 306 | 岩崎 | システム管理者。担当の操作は住人と同じ |
| 309 | 船本 | 住人 |
| 20x | ▲▲ | 住人 |
| 505 | 松谷 | 管理者 |

役割は2つあります。システム管理者は「管理」の画面を開けます。管理者は、日付の備考や特別手当を直せます。管理者には、毎月1万円の管理者手当が報酬に上乗せされます。月の途中で管理者を変えても、その月の手当は元の管理者のままです。新しい人への手当は翌月から付きます。306岩崎はシステム管理者のまま、担当の画面では住人です。505松谷が、最初の管理者です。

下のボタンは「カレンダー」と「報酬集計」です。システム管理者で見ているときだけ「管理」が増えます。画面上部には「システム管理者として見ています」「管理者として見ています」「住人として見ています」のどれかが出ます。

「今のユーザー（デモ用）」で、見ている人を切り替えられます。説明のときは、住人の画面と管理者の画面をここで見せ分けます。

最初から入っている担当は見本です。変えすぎたあとに戻すときは、「サンプルのシフトに戻す」を押します。確認のあと、それまでの担当とメモは消えます。住人、役割、振込先は残ります。

## カレンダーの見方

下の「カレンダー」が、いつ誰が担当かの画面です。

- 「前月」「今月」「翌月」で月を変える。日曜と月曜はお休みで、担当はありません。
- 「1週目」「2週目」は、その週の位置まで移動するリンクです。日付はその下に月の終わりまで並び、スクロールして見ます。今月を開くと、今日を含む週まで移動します。6週ある月は、リンクが2段になります。
- 日付のカードには、ゴミの種類、担当者、報酬が出ます。空きは「空き枠（募集中）」です。
- 緑のふちは、空きがある日です。「今日」は緑の枠で囲みます。
- 交代を頼んでいる日には「交代してください🙏」と出ます。決まるまで、もとの担当者のままです。
- 「+1,000円」は特別手当です。その日の報酬は6,000円です。ふだんは5,000円です。
- 「備考あり」は、立ち会いの時間など、管理者からのメモがある日です。

ゴミの色は、画面上部の丸い印と同じです。

| 曜日 | ゴミ |
| --- | --- |
| 日曜・月曜 | お休み |
| 火曜 | リサイクル。第4火曜だけ不燃 |
| 水曜・土曜 | 燃える |
| 木曜 | プラ |
| 金曜 | ペット |

## 日付を押したとき

その日の詳細が開きます。報酬、備考、前日の申し送り、担当者が見えます。申し送りは、直前に仕事があった日のメモです。日曜・月曜をはさむときも、その前の稼働日のメモを見ます。

空き枠がある人は「この日を担当する」を押せます。同じ日に、同じ人が2枠入ることはできません。

自分が担当の日は、次ができます。

- 「申し送りメモを書く」で、次の人へ伝える。例は「雨のため外掃除スキップしました」。書き終わったら「申し送りを保存」。
- 「交代を募集する（キャンセル）」で、代わりの人を募る。やめるときは「交代の募集を取り消す」。

交代を引き受ける人には「交代で担当する」が出ます。

## 自分の日と空き枠だけ見る

カレンダーのボタンは、押すとひと月分の小さなカレンダーに変わります。金額は出ません。緑の日だけが、探している日です。どちらかがオンのときは、そのボタンが「週表示に戻す」になります。押すと、週ごとの一覧に戻ります。

- 「自分の担当日のみ表示」: 緑の日に「担当」と出ます。
- 「空き枠のみ表示」: 空きと、交代募集中の日に「空き」と出ます。
- 両方押すと、自分の担当で、かつ空き枠もある日だけが緑になります。

日付を押すと、いつもと同じ詳細が開きます。

## 報酬集計

下の「報酬集計」を押します。見ている月の数字です。月はカレンダーと同じ「前月」「今月」「翌月」で変えます。

- 稼働枠、確定、空き枠、交代募集の数
- 確定した報酬の合計。空きがすべて埋まったときの見込みも出ます
- 「もし、空いている枠をあなたが担当すると」は、いまの自分があと何回入れそうかの試算です。すでに入っている日は数えません
- 「部屋ごとの報酬」は、登録されている住人それぞれの回数と金額です。管理者手当がある行は「5,000円 + 10,000円 (管理者手当)」のように出ます。月の途中で管理者になった人は、その月は「管理者手当は翌月から付きます」と出ます。見ている人の行が緑になります。振込先がある人は、名前の右に銀行名と口座番号の下4桁が薄いグレーで出ます。支店名、口座種別、名義、番号の全文は出ません。銀行名も番号もない人には、この文字は出ません

「この月の報酬をCSVでダウンロード」で、その月の表を保存できます。ファイル名は `報酬集計-2026-11.csv` のように月が入ります。中身は部屋、名前、担当回数、特別手当回数、管理者手当、報酬、銀行名、支店名、口座種別、口座番号、口座名義と、最後の合計です。報酬には管理者手当が含まれます。口座番号は全文です。Excelで開ける形式です。試算の「もし担当すると」は入りません。報酬集計を開ける人は、誰でもこのファイルを保存できます。

## システム管理者だけできること

306岩崎だけが使えます。下に「管理」が出ます。ほかの人には、この画面は出ません。日付の備考や担当の変更は、この画面ではできません。

- 住人を追加する。部屋と名前を入れると、住人としてログインの部屋一覧に出ます。振込先は空です。
- 「削除」で、その住人を名簿から外す。確認のあと、その人の担当は空き枠に戻ります。
- 部屋と名前を直す。すでに入っている担当は、同じ人のまま名前だけ変わります。
- 振込先を登録する、直す、空にして消す。項目は銀行名、支店名、口座種別（普通・当座）、口座番号、口座名義です。口座番号は8桁までの数字です。ハイフンは、保存のときに外れます。カードには振込先の全文が出ます。まだ無い人は「振込先は未登録です」です。
- 「管理者にする」「住人に戻す」で、日付を直せる人を決める。

システム管理者は削除できません。増やすこと、外すこともできません。306岩崎のままです。岩崎を「管理者にする」と、管理画面に加えて、日付の備考や特別手当も直せます。

部屋は10文字まで、名前は20文字までです。同じ部屋番号は登録できません。銀行名と支店名は30文字まで、口座名義は40文字までです。

追加した住人も、役割も、振込先も、そのブラウザに保存されます。「サンプルのシフトに戻す」を押しても、消した住人は戻りません。その人の見本の担当は空き枠になります。役割と振込先も戻りません。

## 管理者だけできること

管理者で見ているとき、日付の詳細の下に「管理者の操作」が出ます。

- 「備考の編集」に書いて「備考を保存」。例は「10:00〜 消火栓点検の立ち会いあり」
- 「特別手当（+1,000円）を付与」で、その日を6,000円にする
- 「募集人数を2名にする（台風翌日など）」で、その日を2人にする。2枠目に人が入っているときは、先にその枠を「空き枠」にしないと1人には戻せません
- 「代わりに担当者を決める」で、スマホが苦手な人の代わりに担当を入れる。2人の日は「1枠目を代わりに決める」「2枠目を代わりに決める」です。「空き枠」を選ぶと、その枠が空きます

2人の日は、担当した人それぞれに同じ報酬が付きます。

## データについて

担当、メモ、見ている人、住人の部屋と名前、振込先、誰が管理者かは、そのブラウザに保存されます。別のスマホで開くと、最初の見本から始まります。サーバーにはまだ送っていません。
