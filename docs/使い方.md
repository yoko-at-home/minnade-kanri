# みんなできれいの見方と使い方

ゴミ出し管理、清掃業務を、住人で交代する試作品です。スマホの縦画面で見る想定です。パソコンでも、中央の細い画面で同じように操作できます。

まだ試作品です。担当、メモ、住人、振込先、確定した報酬は、そのスマホの中だけに残ります。ほかの人の画面とは共有されません。

## 開く

https://minnade-kirei.vercel.app

ホーム画面に追加すると、アプリのように開けます。

## 入る

1. 合言葉に `1234` と入れて、「合言葉を確認する」を押す。
2. 「あなたはどの部屋ですか？」から、自分の部屋を選ぶ。

最初の部屋は次のとおりです。

| 部屋 | 名前 | 最初の役割 |
| --- | --- | --- |
| 306 | 岩崎 | システム管理者。担当の操作は住人と同じ |
| 309 | 船本 | 住人 |
| 20x | ▲▲ | 住人 |
| 505 | 松谷 | 管理者 |
| 管理会社 | 担当 | 報酬のCSVを保存するだけ。担当には入らない |

役割は次のとおりです。

- 住人は、自分の担当と自分の報酬を見ます。
- 管理者は、日付の備考、募集人数、代わりの担当を直せます。管理者は2人までです。管理者手当はひとり毎月5,000円で、変えた翌月から付きます。月の途中で管理者を変えても、その月の手当は元の管理者のままです。
- システム管理者は「管理」の画面を開けます。報酬集計では、管理者と同じく全員の金額を見て、終わった月の報酬を確定できます。日付の備考を直すには、別に「管理者にする」必要があります。306岩崎はシステム管理者のまま、最初は担当の画面では住人です。505松谷が、最初の管理者です。
- 管理会社は、全員の報酬CSVと、担当者の名前が付いた月のカレンダーだけを見ます。担当には入れません。管理者にもできません。

下のボタンは「カレンダー」と「報酬集計」です。システム管理者で見ているときだけ「管理」が増えます。画面上部には「システム管理者として見ています」「管理者として見ています」「住人として見ています」「管理会社として見ています」のどれかが出ます。

「今のユーザー（デモ用）」で、見ている人を切り替えられます。説明のときは、住人、管理者、管理会社の画面をここで見せ分けます。

最初から入っている担当は見本です。変えすぎたあとに戻すときは、「サンプルのシフトに戻す」を押します。確認のあと、それまでの担当とメモは消えます。住人、役割、振込先、確定した月は残ります。確定した月の担当は、戻したあともそのままです。管理会社の画面には、このボタンは出ません。

## カレンダーの見方

下の「カレンダー」が、いつ誰が担当かの画面です。開いたときは月表示です。

左のボタンで前の月、右のボタンで次の月に移ります。中央は見ている月です。見ている月が今月のときは、中央がピンクです。別の月を見ているときは「今月に戻す」が出ます。日曜と月曜はお休みで、担当はありません。

「月表示」と「週（詳細）表示」で、同じ月の見方を切り替えます。

### 月表示

ひと月分の小さなカレンダーです。金額は出ません。日付を押すと、その日の詳細が開きます。

- ピンクの日は、空き枠がある日です。
- 名前は、担当が決まっている人です。
- 「2人」は、2人募集の日で、2枠とも空いている日です。
- 「あと1人」は、2人のうち1人は決まっていて、もう1人を募集している日です。
- 担当が埋まっている日は白で、名前だけが出ます。交代を頼んでいる日も、担当者がいるので白です。
- お休みはグレーです。

ゴミの色は、日付の横の丸い印と同じです。

| 曜日 | ゴミ |
| --- | --- |
| 日曜・月曜 | お休み |
| 火曜 | リサイクル。第4火曜だけ不燃 |
| 水曜・土曜 | 燃える |
| 木曜 | プラ |
| 金曜 | ペット |

### 週（詳細）表示

日付のカードが、月の終わりまで並びます。「1週目」「2週目」は、その週の位置まで移動するリンクです。今月を週表示にすると、今日を含む週まで移動します。6週ある月は、リンクが2段になります。

- カードには、ゴミの種類、担当者、報酬が出ます。報酬は1枠5,000円です。空きは「空き枠（募集中）」です。
- 緑のふちは、空きがある日と、交代を頼んでいる日です。「今日」は緑の枠で囲みます。
- 交代を頼んでいる日には「交代してください🙏」と出ます。決まるまで、もとの担当者のままです。
- 「備考あり」は、立ち会いの時間など、管理者からのメモがある日です。
- 申し送りを保存した日は、カードの下にその文が出ます。1行に収まるときは、その文だけです。長いときは1行目だけ出て、2行目以降は「...」です。「...」を押すと全文が出ます。もう一度押すと1行に戻ります。

## 日付を押したとき

その日の詳細が開きます。報酬、備考、前日の申し送り、担当者が見えます。申し送りは、直前に仕事があった日のメモです。日曜・月曜をはさむときも、その前の稼働日のメモを見ます。

空き枠がある人は「この日を担当する」を押せます。同じ日に、同じ人が2枠入ることはできません。管理会社は担当に入れません。

自分が担当の日は、次ができます。

- 「申し送りメモを書く」で、次の稼働日の人へ伝える。例は「雨のため外掃除スキップしました」。書き終わったら「申し送りを保存」。
- 「交代を募集する（キャンセル）」で、代わりの人を募る。やめるときは「交代の募集を取り消す」。

交代を引き受ける人には「交代で担当する」が出ます。

報酬を確定した月は、黄色い案内が出て、担当の変更、申し送り、備考、代わりの担当はできません。

## 報酬集計

下の「報酬集計」を押します。見ている月の数字です。月の変え方はカレンダーと同じです。担当1回につき5,000円です。この画面のカレンダーは見るだけです。日付を押しても詳細は開きません。

### 住人

自分の回数と金額だけが出ます。ほかの部屋の報酬は出ません。

カレンダーでは、自分の担当日が黄色です。ほかの担当日は名前だけです。誰も入っていない日はグレーです。

その月の報酬が確定しているときは、「この月の報酬は確定しています。担当は変更できません。」と出ます。確定のボタンは出ません。

「この月の自分の報酬をCSVでダウンロード」で、自分の行だけを保存できます。ファイル名は `報酬集計-2026-11-306.csv` のように、月と部屋が入ります。ほかの人の振込先は入りません。

### 管理者とシステム管理者

稼働枠、確定、空き枠、交代募集の数が出ます。確定した報酬の合計と、空きがすべて埋まったときの見込みも出ます。

「部屋ごとの報酬」は、登録されている住人それぞれの回数と金額です。管理会社の行はありません。管理者手当がある行は「5,000円 + 5,000円 (管理者手当)」のように出ます。月の途中で管理者になった人は、その月は「管理者手当は翌月から付きます」と出ます。見ている人の行が緑になります。振込先がある人は、名前の右に銀行名と口座番号の下4桁が薄いグレーで出ます。支店名、口座種別、名義、番号の全文は出ません。

カレンダーでは、自分の担当日が黄色です。ほかの担当日は名前だけです。誰も入っていない日はグレーです。

「この月の全員の報酬をCSVでダウンロード」で、その月の表を保存できます。ファイル名は `報酬集計-2026-11.csv` です。中身は部屋、名前、担当回数、管理者手当、報酬、銀行名、支店名、口座種別、口座番号、口座名義と、最後の合計です。報酬には管理者手当が含まれます。口座番号は全文です。Excelで開ける形式です。

終わった月だけ、「この月の報酬を確定する」が押せます。今月と来月は押せません。押すと確認が出て、「確定する」か「やめる」を選びます。確定すると、そのときの担当、金額、振込先が残ります。確定したあとは担当を変えられません。口座をあとから直しても、確定した月の集計とCSVは変わりません。確定を取り消すボタンはありません。

### 管理会社

金額のカードと確定のボタンは出ません。「この月の全員の報酬をCSVでダウンロード」と、担当者の名前が付いた月のカレンダーだけです。空き枠はグレーです。管理会社自身の担当はないので、黄色にはなりません。

## システム管理者だけできること

現在のところ、306岩崎だけが使えます。下に「管理」が出ます。ほかの人には、この画面は出ません。日付の備考や担当の変更は、この画面ではできません。

システム管理者は1人にします。交代するときは、今のシステム管理者が次の住人を選び、確認してから渡します。渡し終わるまで、元の人がシステム管理者です。管理会社には渡しません。渡したあとも、元の人は住人として残します。部屋を出るときは、交代のあとで名簿から外します。この渡し方のボタンは、まだ画面にありません。それまでは306岩崎のままです。

この人は、全員の振込先と確定した報酬を扱います。将来は、この役につくときに、振込先などの機密を守る契約を結ぶ案を検討します。システム管理者としての報酬も、担当1回の5,000円、管理者手当の5,000円と並べて、別の金額として検討します。

- 住人を追加する。部屋と名前を入れると、住人としてログインの部屋一覧に出ます。振込先は空です。
- 「削除」で、その住人を名簿から外す。確認のあと、その人の担当は空き枠に戻ります。確定した月の担当は戻りません。
- 部屋と名前を直す。すでに入っている担当は、同じ人のまま名前だけ変わります。
- 振込先を登録する、直す、空にして消す。項目は銀行名、支店名、口座種別（普通・当座）、口座番号、口座名義です。口座番号は8桁までの数字です。ハイフンは、保存のときに外れます。カードには振込先の全文が出ます。まだ無い人は「振込先は未登録です」です。
- 「管理者にする」「住人に戻す」で、日付を直せる人を決める。管理者は2人までです。

システム管理者は、いまの画面では削除できません。増やすこと、外すこともできません。岩崎を「管理者にする」と、管理画面に加えて、日付の備考や代わりの担当も直せます。そのときは管理者2人の数に入ります。

管理会社のカードは「報酬のCSVを保存するだけです。担当には入りません。」と出ます。編集、削除、「管理者にする」はありません。

部屋は10文字まで、名前は20文字までです。同じ部屋番号は登録できません。銀行名と支店名は30文字まで、口座名義は40文字までです。

追加した住人も、役割も、振込先も、そのブラウザに保存されます。「サンプルのシフトに戻す」を押しても、消した住人は戻りません。その人の見本の担当は空き枠になります。役割と振込先も戻りません。

## 管理者だけできること

管理者で見ているとき、日付の詳細の下に「管理者の操作」が出ます。報酬を確定した月には出ません。

- 「備考の編集」に書いて「備考を保存」。例は「10:00〜 消火栓点検の立ち会いあり」。保存すると、入力欄の上に「備考を保存しました」と出ます。
- 「募集人数を2名にする（台風翌日など）」で、その日を2人にする。2枠目に人が入っているときは、先にその枠を「空き枠」にしないと1人には戻せません。
- 「代わりに担当者を決める」で、スマホが苦手な人の代わりに担当を入れる。2人の日は「1枠目を代わりに決める」「2枠目を代わりに決める」です。「空き枠」を選ぶと、その枠が空きます。管理会社は選択肢に出ません。

2人の日は、担当した人それぞれに5,000円が付きます。

## データについて

担当、メモ、見ている人、住人の部屋と名前、振込先、誰が管理者か、確定した月は、そのブラウザに保存されます。別のスマホで開くと、最初の見本から始まります。管理会社の人も、そのスマホの中にいるデータだけを保存できます。サーバーにはまだ送っていません。
